Stack alvo de implementação
BACKEND · PYTHON FastAPI + arquitetura hexagonal. Bounded contexts DDD: Deteccao, Diagnostico, Execucao, Governanca. Orquestração em LangGraph com roteamento condicional por natureza da remediação e contrato tipado AgentState (TypedDict, schema versionado). O grafo roda efêmero dentro de tasks do Step Functions: cada interrupt() encerra a task — duas vezes no ramo de código — e o checkpoint interno (PostgreSQL) protege só o raciocínio intra-task; o estado é serializado de volta à máquina durável ao fim de cada task. LangChain para ferramentas e retrievers.
FRONTEND · ANGULAR Angular 18 standalone components + Signals. Um módulo por visão deste protótipo (console, HITL, avaliação, configuração, integrações, LLMOps), estado via store dedicado. Servido na AWS como ambiente web da squad de Run.
INFRA · AWS LLMs consumidas via MCP do IARA — o gateway corporativo que governa acesso, catálogo de modelos e custo; nenhum agente fala direto com o provedor. Step Functions (dono do estado durável: lifecycle, retries e espera HITL por task token), Lambda (ações), EventBridge (triggers), DynamoDB + OpenSearch (memória), S3 (pós-mortems), Secrets Manager (credenciais das integrações), CloudWatch. Observabilidade da esteira em Langfuse e LangSmith, correlacionada no Datadog.
🔌 Arquitetura de integração
O EasyRun roda na AWS, mas trata sistemas que nem sempre estão nela. As plataformas corporativas entram como adaptadores na borda — o domínio não conhece nenhum SDK.
ENTRADA Webhooks do Datadog e do ServiceNow chegam por API Gateway, são normalizados em evento de anomalia e publicados no EventBridge. Um só formato de entrada, independentemente da origem.
RASTREABILIDADE Adaptadores de ServiceNow (incidente, CMDB, GMUD) e IUClick (bug, kanban) atrás de portas tipadas. Trocar de ferramenta é trocar de adaptador, não reescrever o domínio.
CÓDIGO GitHub App com escopo por repositório para clonar e abrir PR; Devin acionado por sessão. Redação de segredos e allowlist de repositórios rodam antes de qualquer saída — não é opcional no contrato.
EXECUÇÃO Ações de infra via Lambda e SSM na AWS; sistemas fora dela (ERP on-premises, SaaS de terceiro) por API própria, através de conectividade privada. O Executor não presume nuvem.
